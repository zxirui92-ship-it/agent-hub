# Agent Hub 业务工作台

2026-10-15。本轮把调试页面整理为可直接使用的业务前端，沿用已经验证的真实服务接口。实现位于 `web/static/index.html`、`styles.css`、`app.js`，是浏览器原生 HTML/CSS/JavaScript；当前后端是 `web/server.py` 的 Python HTTP 服务，不是 FastAPI，也不是 Swagger 文档页。无需 Node 构建或下载外部字体/CDN资源。

## 启动

```powershell
python -m pip install -r requirements.txt
# 按 .env.team.example 配好自己的变量名映射，保存到本地 .env
python -m scripts.check_live_config
python -m web --port 8765
```

打开 `http://127.0.0.1:8765/`。默认真实 Planner 与七个真实业务实现。没有外部服务时可以显式使用 `--offline` 排练；页面会标为离线演示。页面不会获取、保存或打包模型密钥。

## 操作

- **智能任务**：自然语言描述目标；“仅预览计划”不执行业务；“开始执行”规划并执行。“执行这个目标”会重新规划，页面如实说明，不声称复用预览的固定计划。
- **智能客服**：同一页面会话内多轮聊天。
- **订单追踪**：查询订单、金额和物流；未知订单明确失败，物流资料冲突明确显示。
- **经营周报 / 营销策划 / 数据融合**：中文表单默认来自后端样例，金额为整数分；实际业务结果优先展示，技术细节默认折叠。
- **创作与搜索**：四种任务快捷输入，最终仍由真实 Router 选择 Skill。知识检索使用本地资料；搜索和图片需要相应外部配置。
- **退款审核**：提交订单与实际退款金额，等待时填写审核人和决定，再继续流程。切换助手不会丢掉本页待审核入口。

桌面使用侧栏，窄屏改为下拉选择。请求中显示等待提示，并禁用会话重置，避免丢失尚未完成的结果。新任务保留历史；重置会话清除页面缓存与后端等待任务。页面刷新会创建新会话，状态不跨浏览器刷新或服务重启保存。
